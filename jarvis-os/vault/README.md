# Vault — la memoria de JARVIS OS

Esta carpeta es tu vault de Obsidian. Es la memoria completa del sistema: todo lo que JARVIS lee, escribe o recuerda vive acá adentro, en archivos markdown planos. Sin base de datos.

## Cómo importarla en Obsidian

1. Abrí Obsidian → "Open folder as vault" → seleccioná esta carpeta (`jarvis-os/vault`).
2. Listo. Las 4 subcarpetas ya están armadas.

## Estructura

| Carpeta     | Qué guarda                                                              |
|-------------|---------------------------------------------------------------------------|
| `crudo/`    | Fuentes de verdad que vos configurás a mano (ej: de dónde salen tus métricas) |
| `medio/`    | Lo que generan las skills día a día: `metricas/`, `inbox/`, `plan/`      |
| `pedidos/`  | Tu agenda manual y pedidos recurrentes                                  |
| `salidas/`  | Cierres de día, resúmenes semanales, reflexiones                        |

Regla simple: **si no está acá, no pasó.**

Ver `.claude/skills/vault/SKILL.md` para el detalle de cómo cada skill lee y escribe acá.
